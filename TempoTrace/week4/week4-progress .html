TempoTrace

원곡과 내 연주를 비교해 박자 정확도(%)를 계산하는 핵심 로직을 실제로 구현하고 검증한 과정을 공유합니다.
01. 지난 계획 요약

3주차에 세운 다음 계획

  • 스마트폰 녹음 앱으로 실제 기타 연주 녹음 → onset detection 테스트
  • 원곡 vs 연주 비교 정확도(%) 계산 로직 실제 구현
  • 결과를 웹페이지에서 확인할 수 있도록 연결
02. 진행상황 — 정확도 계산 로직 구현

4단계 알고리즘 구현

3주차에 설계했던 방식을 그대로 코드(accuracy_test.py)로 옮겼습니다.

1단계원곡과 내 연주 각각에서 librosa로 onset(소리 시작 지점) 시각 리스트 추출
2단계원곡의 각 onset마다 내 연주에서 가장 가까운 시각을 찾아 시간차 계산
3단계시간차가 허용 오차(150ms) 이내면 "맞음"으로 판정
4단계정확도(%) = 맞은 개수 ÷ 원곡 onset 총개수 × 100

05. 발견한 이슈와 해결

진행하며 겪은 문제들

  • 파일을 못 찾는 오류 — VS Code에서 디버거로 실행할 때 작업 폴더가 다르게 잡혀 FileNotFoundError 발생 해결: 스크립트 자신의 위치(__file__)를 기준으로 경로를 고정하도록 수정
  • 그래프 제목과 라벨이 겹치는 문제 — 위/아래 그래프 사이 여백이 부족해 텍스트가 겹쳐 보임 해결: plt.subplots_adjust(hspace=0.5)로 간격 조정
06. 사용성 개선

결과 확인 과정을 자동화

기존에는 "파이썬 실행 → JSON 저장 → 브라우저에서 뷰어 페이지 열기 → 파일 직접 선택"까지 여러 단계를 거쳐야 했습니다. 이 과정을 하나로 합쳤습니다.
  • 분석 결과를 웹뷰어 HTML 안에 자동으로 심어서 새 리포트 파일 생성
  • webbrowser 모듈로 스크립트 실행과 동시에 브라우저가 자동으로 열리도록 개선
  • 결과적으로 스크립트 실행 한 번 = 분석 + 결과 확인까지 끝나도록 단순화됨
