TempoTrace

6주차는 강의 대체 일정(2026 AI 페스타 참관)으로 진행하지 않아, 6·7주차 2주 분량의 진행 내용을 함께 보고합니다.

어느 시간대에서 틀렸는지, 연습할수록 얼마나 나아지는지까지 확인할 수 있도록 기능을 확장했습니다.
01. 지난 계획 요약

5주차에 세운 다음 계획

  • 실제 기타 연주를 스마트폰으로 녹음해서 진짜 데이터로 전체 기능 테스트
  • 슬라이더로 찾은 적절한 허용 오차 기준값을 프로그램 기본값으로 반영
  • 결과 화면 UI 마무리 다듬기 (모바일 화면 대응 등)
이번 2주에는 이 중 결과 화면 다듬기(모바일 대응)를 진행하고, 처음 계획서에 있던 시간대별 오류 시각화와 반복 연습 누적 분석 기능을 구현했습니다.
02. 이번 2주 진행 요약

6~7주차에 추가한 기능

기능 ①시간대별 오류 분포 — 곡을 구간으로 나눠서 "몇 초 구간에서 얼마나 틀렸는지"를 막대그래프로 표시
기능 ②반복 연습 기록 — 연습 결과를 계속 누적해서 정확도 변화 추이와 "자주 틀리는 구간"을 분석
개선 ③사용성 — 여러 번의 연주를 한 번에 분석, 모바일 화면 대응, 구간별 상세 정보 말풍선

※ 기능 ①·②는 1주차 계획서의 2단계(시간대별 오차 시각화)와 3단계(반복 연습 추이 분석)에 해당합니다.

03. 기능 ① 시간대별 오류 분포

어느 시간대에서 틀렸는가

  • 곡을 일정한 구간(기본 2초)으로 나누고, 구간마다 놓친 음 / 엉뚱하게 친 음을 집계
  • 가장 많이 틀린 구간을 문장으로 요약해서 표시 예: "가장 많이 틀린 구간: 2~4초, 4~6초, 6~8초 외 2곳"
  • 허용 오차 슬라이더와 연동되어, 기준을 바꾸면 구간별 분포도 즉시 갱신
  • 곡이 길어지면 구간 길이를 자동으로 늘려 최대 15구간으로 유지
회색: 놓친 음 / 빨강: 엉뚱하게 친 음 / 연한 초록: 오류 없음
04. 기능 ② 반복 연습 기록

연습할수록 나아지고 있는가

  • 실행할 때마다 결과를 practice_history.json에 자동 기록 (일시, 정확도, 평균 오차, 구간별 오류)
  • 회차별 정확도 변화를 꺾은선 그래프와 표로 표시 첫 기록 대비 얼마나 올랐는지(%p)도 요약
  • 자주 틀리는 구간: 모든 연습의 구간별 오류를 평균 내어, 반복해서 틀리는 시간대를 찾아냄
회차별 정확도 변화와 자주 틀리는 구간(평균)
05. 개선 ③ 사용성

한 번의 실행으로 여러 연습을 분석

# 기본: original.wav 와 my_take.wav 비교
python accuracy_test.py

# 여러 번의 연습(take)을 순서대로 분석하고 기록에 누적
python accuracy_test.py take1.wav take2.wav take3.wav

# 옵션: 기록에 남기지 않기 / 기록 초기화
python accuracy_test.py take1.wav --no-history
python accuracy_test.py --reset-history
  • 결과 화면이 모바일 화면 폭에도 맞게 정리되도록 반응형으로 개선 (고해상도 화면에서도 선명하게 표시)
  • 그래프 위에 마우스를 올리거나 터치하면 해당 구간·회차의 상세 정보를 말풍선으로 확인
  • 결과 화면이 스스로 데이터를 읽어 그리도록 구조를 정리해, 파이썬 쪽 코드가 단순해짐
06. 실행 화면

터미널 실행 결과

여러 번의 연습을 한 번에 실행하면, 연주마다 결과가 출력되고 마지막에 연습 기록의 정확도 추이가 정리됩니다. 이어서 결과 웹페이지가 자동으로 열립니다.

연주별 정확도, 시간대별 오류, 연습 기록 추이가 순서대로 출력됨
07. 검증

계산 결과와 동작을 점검한 내용

  • 파이썬이 계산한 값과 웹페이지가 다시 계산한 값이 허용 오차 20~300ms의 8개 기준 모두에서 일치 정확도, 놓친 음·엉뚱한 음 개수, 시간대별 집계까지 비교
  • 연습 기록의 누적, 초기화, 기록 제외 옵션이 의도대로 동작
  • 기록이 없거나 1회뿐인 경우, 파일이 없는 경우, 기록 파일이 손상된 경우에도 오류 없이 안내하며 동작
  • PC와 모바일 화면 폭에서 레이아웃 확인 (가로 스크롤 없음), 마우스·터치 말풍선 동작 확인
08. 계획서 대비 진행 현황

1주차 계획서와 비교

1단계onset detection 기반 박자 정확도(%) 계산완료
2단계시간대별 오차를 웹페이지에 시각화완료 (6~7주차)
3단계여러 번 연습한 기록을 누적해서 추이 분석완료 (6~7주차)
3단계 (스트레치)음정(피치) 정확도 분석미진행 (추후 검토)
09. 이슈 / 보완할 점

진행하며 발견한 이슈

  • 모바일에서 말풍선이 바로 사라지는 문제 — 터치하면 브라우저가 마우스가 벗어난 것으로 처리해서 발생 해결: 터치 직후의 해당 이벤트는 무시하도록 수정
  • 연습 기록의 비교 기준이 달라질 수 있음 — 실행할 때마다 허용 오차가 다르면 추이가 왜곡됨 보완: 기록 표에 당시의 기준값(ms)을 함께 표시
  • 곡이 길면 구간이 너무 많아지는 문제 해결: 최대 15구간으로 구간 길이를 자동 조정하고, 곡 끝의 짧은 조각은 마지막 구간에 합침
  • 같은 연주를 다시 실행하면 기록이 중복됨 해결: --no-history 옵션으로 기록에 남기지 않고 실행 가능
  • 실제 기타 녹음 데이터로 전체 기능을 검증하는 단계는 아직 진행 전 — 다음 단계에서 진행 예정
